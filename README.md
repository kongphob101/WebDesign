## สิ่งที่ใช้

- HTML แยก 20 หน้า: แก้ข้อความและรูปในไฟล์แต่ละหน้าได้โดยตรง
- Bootstrap 5.3.8 **เฉพาะ CSS**: อยู่ใน `vendor/bootstrap/bootstrap.min.css`
- CSS ที่เขียนเอง: `css/style.css` แยก property คนละบรรทัด มีหัวข้อคอมเมนต์แบ่งส่วน
- ระยะห่างหลักใช้ `1rem` (16px ตามขนาดฟอนต์เริ่มต้น) ส่วนระหว่างส่วนใหญ่ใช้ `2rem`
- รูป: ใช้ไฟล์เดิมใน `img` และ `img/Car img`
- ฟอนต์ Kanit: เก็บใน `fonts` เพื่อเปิดแบบออฟไลน์ได้
- **ไม่มี JavaScript ในเว็บ** ตามที่ขอ จุดทำงานที่ต้องต่อระบบมีคอมเมนต์ `TODO` อยู่ใน HTML

## Responsive: breakpoint เดียว 425px

Layout ใช้ `container`, `row`, `col-3`, `col-4`, `col-6`, `col-9` ของ Bootstrap
ไม่ได้ใช้ `col-md-*` / `col-lg-*` เพื่อไม่ให้ Layout สลับตาม breakpoint เพิ่มเติม

ท้าย `style.css` มีเพียง:

```css
@media screen and (max-width: 425px) {
  /* เมนูมือถือ / เรียงคอลัมน์ / ปรับระยะห่าง */
}
```

จอใหญ่กว่า 425px ใช้คอลัมน์เดสก์ท็อป ส่วนจอไม่เกิน 425px เรียงการ์ดลงด้านล่าง
ตารางเปรียบเทียบอยู่ใน `table-responsive` ให้เลื่อนแนวนอนเฉพาะตาราง
เมนูมือถือเปิดด้วย checkbox และ CSS เมนูย่อยใช้ `<details>` จึงไม่ต้องมีสคริปต์
Bootstrap เองมี media queries มาตรฐานอยู่ในไฟล์ vendor แต่ CSS/Layout ของงานนี้กำหนดจุดเปลี่ยนเองจุดเดียว

## แก้โค้ดระหว่างพรีเซนต์

1. **แก้ข้อความ** — เปิดไฟล์ HTML ของหน้านั้น แล้วแก้ข้อความใน `<h1>`, `<h2>`, `<p>`
2. **เปลี่ยนภาพ** — แก้ `src="../img/ชื่อรูป.png"`; รูป Banner แก้ `url('../img/ชื่อรูป.png')` ที่ `<section>`
3. **เปลี่ยนจำนวนคอลัมน์** — 3 ใบใช้ `col-4`; 2 ใบใช้ `col-6`; 4 ใบใช้ `col-3` รวมหนึ่งแถวเป็น 12
4. **เปลี่ยนช่องไฟ** — `g-3` ใน `.row`, `gap-3` ใน Flex, `p-3` และ `mt-3` ล้วนใช้ระยะ `1rem`; ระยะเฉพาะส่วนแก้ใน `style.css`
5. **เปลี่ยนสี** — แก้ `--navy`, `--blue`, `--page`, `--pale` ที่ `:root` ด้านบน `style.css`
6. **แก้เมนู** — เมนูเป็น HTML อยู่ในทุกหน้า ถ้าปรับชื่อเมนูให้ค้นหาและเปลี่ยนในทุกไฟล์
7. **หาโค้ดที่ต้องทำต่อ** — ค้นหา `TODO` ใน VS Code

## ขอบเขตของงานตอนนี้

ลิงก์เมนูไปมาระหว่างหน้าได้ ช่องกรอก กดเลือก radio และ checkbox ได้ตาม HTML ปกติ
ปุ่มที่ต้องคำนวณ/กรอง/บันทึกยังไม่มีระบบทำงาน ตารางและผลลัพธ์เป็นตัวอย่างคงที่
หน้ารายละเอียดรถใช้ Corolla Cross เป็นตัวอย่าง หน้าแบรนด์ใช้ Toyota และหน้าอ่านบทความเป็นตัวอย่างหนึ่งเรื่อง
ลิงก์จากรถ/แบรนด์/บทความอื่นจึงเข้าหน้าตัวอย่างเดียวกัน ต้องเพิ่มเนื้อหาหรือระบบเลือกข้อมูลภายหลัง

แผนที่บนหน้าค้นหาเป็นภาพประกอบจาก CSS ไม่ใช่แผนที่จริง ลิงก์ Google Maps เปิดค้นหาสถานที่ได้และต้องใช้อินเทอร์เน็ต
ราคา สเปก รีวิว โปรโมชัน และกำหนดการเป็นข้อมูลตัวอย่างสำหรับการออกแบบ ควรตรวจสอบก่อนใช้เผยแพร่จริง
ภาพอาจไม่ตรงกับรุ่นย่อย สามารถเปลี่ยนไฟล์ใน `img` ได้ภายหลังตามต้องการ
